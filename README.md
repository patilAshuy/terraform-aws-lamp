# terraform-aws-lamp
# 🚀 Terraform AWS LAMP Stack Automation

This project provisions an AWS EC2 instance and automatically installs a LAMP stack using Terraform and shell scripting.

## 🔧 Features
- Infrastructure as Code using Terraform
- Automated LAMP stack setup (Apache, MySQL, PHP)
- One-click deployment
- Outputs public IP for instant access

## 🧰 Tech Stack
- AWS EC2 (Graviton - ARM)
- Terraform
- Shell Scripting
- Linux (Amazon Linux 2)

## 🚀 How to Run

```bash
terraform init
terraform plan
terraform apply
